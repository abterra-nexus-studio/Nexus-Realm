# 🌌 Nexus Realm — Universal Web Reader & Discovery Hub

**Nexus Realm** is an ultra-modern, glassmorphic dark-themed web application designed as a universal reader, discovery hub, and reading tracker across multiple novel & fiction platforms.

![Nexus Realm Preview](https://img.shields.io/badge/Status-Active-brightgreen) ![License](https://img.shields.io/badge/License-MIT-blue) ![HTML5](https://img.shields.io/badge/Frontend-HTML5%20%7C%20CSS3%20%7C%20JS-orange)

---

## ✨ Features

- 📱 **Native Mobile & App Feel**: Built-in glassmorphic UI with dynamic modals, smooth tab switching, and bottom navigation.
- 📚 **Universal Discovery**: Search and explore stories across top platforms like **Webnovel**, **Wattpad**, **Tapas**, **Scribble Hub**, and **Royal Road**.
- 📊 **Reading Tracker & Stats**: Track chapter progress, mark status (*Reading*, *Completed*, *Want to Read*), and view activity logs.
- 💾 **Local Data & Export**: Complete privacy with local storage synchronization and single-click JSON library export/reset options.
- 💎 **Premium Pass Integration**: Direct monetization setup integrated with Gumroad.
